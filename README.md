# Bloom Club
 
Bloom Club is a responsive interest club website developed for the IT312 Web Applications Engineering course.
 
## About the Project
Bloom Club is a community for flower enthusiasts who enjoy floral design, plant care, and creative workshops. The website introduces the club, its team members, and available offerings while providing separate dashboards for club members and managers.
 
## Features
- Responsive Web Design
- Multiple Website Themes
- Club Offerings Catalogue
- Activity Leaders and Instructors Profiles
- Club Member Dashboard
- Club Manager Dashboard
- Form Validation using JavaScript
- Offering Sorting
- Local Storage Functionality
- Real-Time Clock
- Back to Top Button
 
## Technologies Used
- HTML5
- CSS3
- JavaScript
 
## Website Pages
